# AR Layers Directory

## Files die hier moeten komen:

Plaats hier alle PNG/afbeelding layers voor je AR-animaties.

### Naming Convention:
Gebruik een logische naamgeving die correspondeert met je posters, bijvoorbeeld:
- `poster-0-overlay.png` - AR animatie voor targetIndex 0
- `poster-1-layer1.png` - Eerste laag voor targetIndex 1
- `poster-1-layer2.png` - Tweede laag voor targetIndex 1
- etc.

### Test Setup:
Voor nu is er een placeholder:
- `test-overlay.png` - Een simpele test afbeelding voor de eerste demo

**Let op:** Deze afbeeldingen moeten transparante PNG's zijn voor de beste AR-ervaring.
